# INvisibleART Lead Engine

A conversion-focused system designed to capture leads and automate strategy call bookings.

## Features
- Lead capture form
- Backend lead storage
- Calendly integration
- Auto scheduling flow
- Pre-filled booking experience

## Purpose
To eliminate manual follow-ups and convert inbound traffic into qualified business calls.
